# Alisher Tursunov — Notes

A small, static personal blog built with plain HTML, CSS, and JavaScript. No build tools or dependencies are needed.

## Publish a post

1. Open `posts.js`.
2. Copy the example post object and paste it at the start of the `BLOG_POSTS` list.
3. Set a unique URL-friendly `slug`, a title, a date (`YYYY-MM-DD`), a category, and a short excerpt.
4. Add your post as paragraphs in the `content` array—one string per paragraph.
5. Save and publish the change to the repository. Posts are automatically sorted newest first.

The site is static, so posts live right in the repository and can be added by editing `posts.js` on GitHub—no CMS or install required.
